Install Bangladesh affairs

On Chrome, open this app over HTTPS (or localhost), then choose Install Bangladesh affairs from the address bar or Chrome menu → Cast, save and share → Install page as app.

On Android, choose Install app or Add to Home screen in Chrome’s menu. The browser decides when an installation prompt is available.

After the first complete load, the map and study library work offline. Source websites require a connection.
